## Convenções rápidas

- **PK de entidade**: `UUID` — `gen_random_uuid()` no banco, `GenerationType.UUID` no JPA.
- **PK de lookup**: `INTEGER GENERATED BY DEFAULT AS IDENTITY`.
- **`Code`**: `INTEGER` incremental (1 em 1), presente só nas entidades operacionais — é o número "bonito" exibido no front.
- **Soft delete**: `CreatedAt` / `EditedAt` / `DeletedAt` (TIMESTAMPTZ). Queries devem filtrar `DeletedAt IS NULL`.
- **Nomes**: PascalCase com aspas duplas (`"Claim"`, `"ClaimSituationId"`). `spring.jpa.properties.hibernate.globally_quoted_identifiers=true`.
- **Dinheiro**: `NUMERIC(15,2)` — nunca `float`/`double`. **NDVI**: `NUMERIC(4,3)`. **Percentual**: `NUMERIC(5,2)`.
- **Lookups de estado**: sempre terminam em `*Situation` (nunca `*Status`).
